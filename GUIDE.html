4 CSRF Token — Why & How

S/4HANA on-prem requires CSRF tokens for all modifying requests (POST, PUT, DELETE)

CSRF Token Handshake
⚠️ Common CSRF Pitfalls Tokens expire with the HTTP session. If you get a 403 Forbidden response, clear _csrfToken and re-fetch. In the code, the token is fetched once and cached for the upload batch.

8 Key Code Walkthrough

The most important code blocks explained visually

Upload.controller.js — CSRF Token Fetch 
_fetchCsrfToken: function () {
    var that = this;
    return new Promise(function (resolve, reject) {
        // Skip if already cached
        if (that._csrfToken) { resolve(that._csrfToken); return; }

        $.ajax({
            url:     that._serviceUrl + "/",
            method:  "GET",
            headers: { "X-CSRF-Token": "Fetch" },  // ← magic header
            success: function (data, status, xhr) {
                that._csrfToken = xhr.getResponseHeader("X-CSRF-Token");
                resolve(that._csrfToken);
            },
            error: function (xhr) {
                reject(new Error("CSRF fetch failed: " + xhr.status));
            }
        });
    });
},
Upload.controller.js — Sequential File Upload (Promise Chain) 
_uploadFilesSequentially: function (aItems, sToken) {
    var that = this, aResults = [];

    // Reduce items into a promise chain: file1 → file2 → file3 → ...
    return aItems.reduce(function (pChain, oItem) {
        return pChain.then(function () {
            return that._uploadSingleFile(oItem, sToken)
                .then(function (oResult) { aResults.push(oResult); });
        });
    }, Promise.resolve()).then(function () {
        return aResults;
    });
},
Upload.controller.js — Single File POST 
_uploadSingleFile: function (oItem, sToken) {
    var oFile     = oItem.getFileObject();
    var sMimeType = oFile.type || "application/octet-stream";

    return new Promise(function (resolve) {
        $.ajax({
            url:     that._serviceUrl + "/AttachmentContentSet",
            method:  "POST",
            headers: {
                "X-CSRF-Token":           sToken,     // ← from step 1
                "Content-Type":            sMimeType,  // ← file MIME type
                "Slug":                    sSlug,      // ← URL-encoded filename
                "BusinessObjectTypeName":  sObjectType,
                "LinkedSAPObjectKey":      sObjectKey
            },
            processData: false,   // ← don't transform binary
            contentType: sMimeType,
            data:        oFile,    // ← raw File object
            success: function () { resolve({ success: true }); },
            error:   function (xhr) { resolve({ success: false }); }
        });
    });
},

Error Flow Diagram
Important: Never reject upload promises! Each file's upload promise always resolve()s (with success: true/false), so a single file failure never aborts remaining files. The final summary counts successes and failures.

10 Backend Setup (S/4HANA)

Steps to configure the OData service on the ABAP side

Transaction SEGW — Create/Check OData Service

For custom services: create a project in SEGW, define an Entity Type with Media flag enabled. Generate runtime artifacts. For the standard API, this step is already done — just activate the service.

Transaction /IWFND/MAINT_SERVICE — Activate Service

Register and activate API_CV_ATTACHMENT_SRV (or your Z-service) in the gateway hub. Assign a system alias pointing to the backend.

DPC_EXT — Implement CREATE_STREAM (Custom Only)

Redefine method /IWBEP/IF_MGW_APPL_SRV_RUNTIME~CREATE_STREAM. Read binary data from IS_MEDIA_RESOURCE-VALUE, the filename from IV_SLUG, and MIME type from IS_MEDIA_RESOURCE-MIME_TYPE.

ICF Node — Verify HTTP handler

In transaction SICF, verify the path /sap/opu/odata/sap/ is active. The handler class CL_HTTP_EXT_ODATA processes all OData requests.

Authorization — S_SERVICE Object

Users need authorization object S_SERVICE with the service name. For attachment APIs, also check S_WFAR_OBJ for archive link permissions.

ICM Server — Adjust Upload Size Limit

Profile parameter icm/HTTP/max_request_size_KB defaults to ~100 MB. Adjust in RZ10 if you need larger file uploads.
